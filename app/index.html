Kode Avatar

Make your own animated face for the Kode Dot. Describe your character, let Claude or ChatGPT draw each animation as a Lottie file, paste the answers here, and download a face pack the Dot can install. Everything runs in your browser; nothing is uploaded.

1 Your character

The better you describe it, the more alike the twelve animations come out. Name colours, shapes and one prop.

Claude ChatGPT

2 The animations

For each card: Copy prompt → paste it in Claude or ChatGPT → copy the JSON it answers → Paste answer. Make Idle first and keep using the same chat, so the AI reuses the same drawing. Only Wake up and Idle are needed; the rest is optional.

3 Download and install

With a microSD card

  1. Format the card as FAT32.
  2. Unzip the download. It holds a folder kode.
  3. Copy that kode folder to the root of the card, so it holds /kode/kode.json.
  4. Put the card in the Dot and restart it.

Back to Kody: take the card out and restart.

Over Wi-Fi

  1. Put the files from the kode folder online, for example in a public GitHub repository.
  2. Open the Dot's console over USB-C (any serial terminal).
  3. Type, with the link to your kode.json:
function name="assets_update" arg="https://raw.githubusercontent.com/YOU/REPO/main/kode.json"

Back to Kody: function name="assets_update" without arg.

This is a fan tool, not made or supported by Kode. The checks here are kodeOS's own pack rules (canvas, size, frame rate, depth), but the preview is drawn by your browser, not by the Dot. A Lottie can look right here and still differ on the Dot. Try it first from a card: that is the easiest to undo.
